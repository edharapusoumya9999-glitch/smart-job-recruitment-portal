# Smart Job Recruitment Portal

A web-based Job Recruitment Portal developed using Java, Spring Boot, REST API, Spring Data JPA, Hibernate, and MySQL.

## 📌 Project Overview

The Smart Job Recruitment Portal is designed to simplify the recruitment process by providing a platform for managing job opportunities, candidates, and job applications.

The backend is developed using Spring Boot and REST APIs, with MySQL used for database management.

## 🚀 Features

- User Registration
- User Login
- Job Management
- Add Job Details
- View Available Jobs
- Update Job Information
- Delete Job Information
- Candidate Management
- Job Application Management
- CRUD Operations
- REST API Integration
- MySQL Database Integration

## ▶️ How to Run the Project

1. Clone the repository.
2. Open the project in Eclipse, IntelliJ IDEA, or Spring Tool Suite.
3. Configure MySQL in `application.properties`.
4. Create the required database.
5. Run the Spring Boot application.
6. Test the REST APIs using Postman.

## 🗄️ Database

The project uses MySQL with Spring Data JPA and Hibernate for database operations.
